AScoring model — six dimensions every L3 solution is measured on

Dimension weights are fixed across all 30 components so rankings are comparable. The component-specific KPIs in section C feed each dimension; the generic KPIs below apply to every component regardless of phase.

GATES Mandatory pass / fail — any failure makes a solution ineligible

TIERS Eligibility ranking by composite score

KPI score  = 100 if value meets Target · 60 at Min · linear between · 0 below Min
Dimension  = mean of its KPI scores (component-specific + generic)
Composite  = 0.30·D1 + 0.20·D2 + 0.15·D3 + 0.10·D4 + 0.15·D5 + 0.10·D6
Tie-break  = higher D1 → lower cost per 1k runs → more groups already adopting
Challenger replaces champion only if composite ≥ champion + 5 and no gate regresses
